# Art direction

The direction, stated once so it can be checked against.

## The idea

**A bright craft table.** A saturated teal ground, a warm wooden shelf of ink
bottles, cream cards with chunky rounded edges and hard bottom bevels, and one
amber accent for progress and reward. The page is a real sheet of rag paper and
is the only quiet, tactile thing on screen — which is exactly why it holds the
eye.

The direction went through two wrong turns worth recording. A sepia "field
journal" read as a literary artefact rather than a game. A deep indigo shell
read as a premium indie puzzle. Casual mobile is **high-key and saturated**: the
background is bright, the cards are cream rather than dark, the buttons are
thick and bevelled, and the type is heavy. Teal specifically, because it is the
one hue none of the eighteen inks use, so every ink stays legible against it.

Two rules keep it coherent:

1. **On the page it is pigment.** The ink layer multiplies into the sheet, so
   the paper's grain, foxing and vignette read through every mark. Nothing UI
   is ever drawn onto the page except the first-run hint and the ruled border.
2. **Off the page it is a toy.** Saturated ground, wooden shelf, cream cards,
   thick bottom-bevelled buttons. Amber is reserved for things the player
   earned.

## The surface recipe

Every raised thing in the game — the shelf plank, the progress chip, panels,
buttons, note cards — is built the same way. That repetition is what makes it
feel like one object rather than a pile of components.

```
background  : top-lit linear gradient (lighter → darker)
bottom edge : a hard 3–8px darker edge, no blur — this is the casual-game
              signature, and it is what makes a button feel pressable
drop shadow : one soft shadow under the hard edge
radius      : 16–30px, chunkier than product UI
```

Pressing a control translates it *down onto its own bottom edge* rather than
scaling it. That is the interaction that reads as physical.

The Pixi shelf follows the identical recipe with layered fills, because Pixi
Graphics has no gradient primitive.

## Type

Sized in absolute **px**, never `rem`. `rem` multiplies against a root size the
game does not control — a WebView with a different default, or a player who has
raised their system text size, silently rescales the whole interface — and a
game's controls should be the physical size the designer chose. The floor is
13px for anything a player must read and 12px only for tracked all-caps
micro-labels. The Pixi scene sizes its text in *design units*, of which there
are 720 across the screen, so every value there is roughly double its CSS px.

- **Display** — `Arial Rounded MT Bold / SF Pro Rounded / ui-rounded` at 900,
  with a stacked hard shadow so the wordmark is extruded like the buttons under
  it. The wordmark was a serif for a while and it read as a book.
- **UI voice** — the system sans at 800–900 weight. This is what reads as a game
  on a phone, and it ships no font. Used for every control, label, count and
  heading.
- **Identity** — `Iowan Old Style / Palatino / Georgia / serif` for discovery
  titles in Field Notes. It is the trace of the journal the game grew out of,
  kept where it is texture rather than where it has to carry the game's name.
- **Marginalia** — `Bradley Hand / Chalkboard SE / Segoe Print / cursive`, only
  for the one-line notes under a discovery and the first-run hint on the page.

**Why no webfont.** The UI voice is a system sans on purpose: a downloaded
display face would block first paint for text that is mostly short labels, and
any coverage gap would land on the most visible surface. The stacks above are
legible everywhere and the direction survives every fallback in them.

## Everything is procedural, except the key art

Two image files ship. Everything else — every texture, every icon, every sound —
is generated by the game's own code at runtime.

- **`public/title-hero.jpg`** — painted key art for the title screen: three
  corked ink bottles on a warm wooden shelf above a rag page where blue, gold
  and green pigment are mid-bloom into vines, fire-leaf and water. Masters live
  in `src/assets/art/`; `npm run thumbnail` re-encodes into `public/`. Framed as
  a rounded card rather than blended into the background, because it carries
  its own opaque teal and a card is both honest about that and the same
  raised-surface language as every control below it.
- **`public/thumbnail.jpg`** — the 512×512 store tile, the same craft-table
  fantasy as the hero plus a chunky cream **Inkbloom** wordmark (and the
  "paint inks that live" tagline). Painted key art, not a sim crop: a
  simulation screenshot reads as a soft journal smear at arm's length.

- **Paper** (`scene/paperTexture.ts`) — fibre speckle, long pressed fibres, age
  foxing, lamp falloff, an optional drafting grid. Deterministic per sheet seed,
  so grain never crawls between frames and a torn-off page gets a new sheet.
- **Ink** (`scene/simTexture.ts`) — granulation from each cell's fixed paper
  grain and watercolour edge darkening on any cell touching bare paper. The
  mark is deliberately **not** blurred: a cell is only a few device pixels
  wide, so even a one-cell blur turns a pile of sand into a brown cloud and
  destroys the grain. Bilinear magnification supplies exactly enough softness.
  Only the wet halo underneath gets a wide blur.
- **Shelf** (`scene/handDrawn.ts`) — corked bottles drawn for the size they are
  actually seen at, roughly 60 design units: the silhouette is filled with the
  ink itself so the eye reads "the blue one" first, with a darker lower half, a
  meniscus, one specular stripe, a light rim and a lit cork. Locked bottles are
  slate with a hint of their colour — a low-alpha tint just becomes more wood —
  and wear an amber pill across the foot of the slot carrying the number of
  discoveries that opens them. **The pill is sized from its own number**, not
  from the bottle. Every version that did it the other way round broke the
  moment the shelf changed: a corner disc narrower than a two-digit gate, then
  a pill shorter than the digits' line box, with the gold rim running through
  them. `visual-qa` now publishes both boxes and asserts the number fits.
- **Audio** (`audio/inkAudio.ts`) — a nib on rag paper, fire ticking at a
  density driven by the simulation's burning-cell count, a gold chime for a
  discovery, a sparse D-dorian bed, and a continuous *page voice* that follows
  how busy the sheet is.

  Three rules keep a busy page from turning into *density*, and all three were
  written after it did. **One rate limit for every continuous stroke sound**,
  because they were separate methods, only one was limited, and pointermove
  fires at 60-120Hz. **A hard voice budget** — past it a sound is dropped
  rather than queued, since a late sound is worse than a missing one. And
  **intensity is loudness, not rate**: past a floor, a bigger fire gets bigger
  crackles rather than more of them. Measured on a continuous ember drag over a
  burning page: 12 concurrent voices before, 5 after.

  Fixing the density did not fix the *timbre*, and the game still sounded like
  static. Four more rules, from the second pass:

  - **The noise buffer is pink, not white.** White has equal power per hertz,
    so most of its energy sits in the top two octaves; everything built on it
    read as hiss. Pink falls at 3dB/octave, which is what paper, fire and
    rushing water actually do. One change, every burst warmer. Normalise the
    result rather than scaling it by a constant — the filter's output level is
    not the input's, and a guessed constant re-gains the whole game.
  - **Continuous sounds are transients, not textures.** The nib was a 90ms band
    at **Q 0.7** repeated every 70ms, which is to say ninety milliseconds of
    hiss seventy milliseconds apart. It is now a 32ms tick at Q 8 whose pitch
    moves per stroke; a run of them reads as a scrape. Fire crackles are 20ms
    pops at Q 9 rather than 85ms washes at Q 2.5.
  - **Noise sweeps or it is a texture.** Every continuous sound now ramps its
    filter over the burst's life. A static band of noise is a hiss however
    short; the same noise with a falling filter is a fizz, a tick or a pop.
  - **The page bed rumbles rather than hisses.** It was a *bandpass at Q 0.6*,
    which is barely a filter — broadband noise held open whenever anything was
    on the page, and the single loudest reason the game sounded like static.
    It is now a 260Hz lowpass at half the level.

  Plus tone shaping across the whole mix before the limiter: a highpass at 80Hz
  so stacked bursts do not build mud, and a lowpass at 6.2kHz to take off the
  octave where noise stops being texture and starts being hiss. Per-sound fixes
  cannot do that job — it has to be the whole mix or the sounds stop matching.

  **This is measured, not asserted.** `visual-qa` drives the page into its
  loudest state — a burning thicket with a nib dragged through it — and samples
  the master output's **spectral flatness**, which is 1.0 for white noise and
  falls toward 0 as a signal becomes tonal. The old synthesis measured 2.0e-4
  at a 1068Hz centroid; the shipped one measures 1.1e-5 at 415Hz — twenty times
  less flat and an octave warmer — and the run fails if it drifts back.

  The page voice is a *permanent* looping source gated only by a bus gain, so
  destroying the Pixi scene never stopped it — the bed droned on through the
  main menu. Continuous page sound is now gated on a `pageSilent` latch that
  the scene sets on teardown, and `visual-qa` asserts the page is quiet after
  returning to the title. Music deliberately survives the trip out; only what
  the *page* was making stops.
- **Key art** (`src/assets/art/`, shipped via `npm run thumbnail`) — craft-table
  teal, wooden shelf of three ink bottles, rag page mid-bloom. The store tile
  carries the **Inkbloom** wordmark; the title hero does not. `scripts/thumbnail.html`
  still grows a sim page for local colour checks and is not the shipping tile.

## Sheets

Paper is not a skin. On Rag and Vellum the ink multiplies into the sheet the way
pigment darkens paper. On Nocturne and Blueprint it *screens*, so the same inks
stop being stains and become light — an ember on Nocturne is a lamp, not a
scorch. The shell tone shifts with the sheet so the whole frame moves together.

## Motion and reward

Shared timings in `scene/palette.ts`.

- The CTA has a hard bottom edge and depresses into it — a physical key press.
- The progress chip punches when the count changes.
- Picking a bottle *pops* it — a scale overshoot that settles — and lifts it
  onto a bright amber card. The left-right shake is reserved for tapping a
  locked bottle, because a shake universally reads as "no"; using it for
  selection made every pick feel like an error.
  The pop is applied as a **size multiplier, never a scale transform**: Pixi
  composes `scaleTransform` after `translateTransform` such that the existing
  translation is scaled too, which at a shelf y of ~1400 design units threw the
  bottle 200 units down the screen.
- A discovery fires three things at once: a particle burst at the cell, a rim
  of the discovery's own colour racing around the sheet, and a reward card
  sliding down from the top. The rim matters most: the player is usually
  watching the reaction, not the counter, and it works even when the discovery
  happened off-screen.
- Panels arrive as bottom sheets with a grab handle — the native mobile gesture.
- A torn sheet flies off with its rotation and shadow intact.

**Reduced motion is a treatment, not an absence.** With it on, ambient loops
stop entirely, toasts fade in place instead of sliding, the tear becomes a fast
crossfade, particle bursts are suppressed, the celebration rim is brief, and the
progress chip marks itself with a gold ring instead of a bounce. Every state
change still reads as a change.

## Fit

Portrait only. The sheet **fills every pixel between the header and the shelf**,
so the grid is derived from the device rather than fixed: 258 rows always, and
as many columns as the available width asks for (roughly 183 on a 9:19.5 phone).
A fixed 150×258 grid had one aspect ratio and the phone had another, which
letterboxed the page and left a band of bare desk down both sides — dead space
on the one screen the player looks at. Cells stay square, so ink reads at the
same scale everywhere.

The sheet takes everything between the HUD and the shelf; the shelf is sized by
its contents, not by a share of the screen, so bottles are the same comfortable
size on every device. The nineteen slots sit in **two rows of ten and nine**.
One row would have put each bottle at roughly 24 design units — a 13px tap
target — whereas two rows cost about 100 units of plank and keep the bottle at
a comfortable size. Safe-area insets are read from the same CSS custom
properties the React shell publishes, so the canvas respects notches and home
indicators without knowing which it is dealing with. On a wide screen the game
stays a phone-shaped column.
